# 案例问答的事实与来源契约

本契约对应 `answer_evidence.py`、案例问答 API、只读 MCP 和两套工作台。验收记录见 [case-qa-acceptance.md](case-qa-acceptance.md)。

## 请求与兼容

`POST /api/product/cases/{case_id}/ask` 及 `/ask/stream` 保留原请求字段，增加可选 `lang: "zh" | "en"`。未传语言仍按问题推断；同一 `turn_id` 改问题或显式语言返回冲突，不重用旧结果。`mode` 保留旧含义，不再用它推断是否调用了模型。

## 回答来源

| 字段 | 含义 |
|---|---|
| `source_mode=model` | 返回通过本轮机械事实检查的模型原答；这不是通用语义正确性证明 |
| `source_mode=deterministic` | 服务端根据授权案例事实组织回答 |
| `source_mode=local` | 浏览器使用已保存案例生成兜底，页面明确标注 |
| `fallback_reason` | `model_unavailable`、`model_empty` 或 `model_evidence_mismatch`；不得把降级标成模型成功 |
| `case_context` | 回答绑定的案例、方案、修订和历史时间 |
| `evidence_usage` | 固定案例指纹、宿主事实来源 `case_snapshot`、每项事实覆盖状态 |
| `citations` | 宿主允许的 `field/label/value`；字段值来自本回合公开案例。派生计数不能冒充数组字段原值 |
| `activity` | 实际运行活动；服务端主动附带事实不伪造为模型工具调用 |
| `evidence_refs` | 相关案例入口，供自行查阅；不意味着本轮读取过入口的全部内容 |

旧回复缺少 `source_mode` 或版本时显示未记录，不追溯补上本地引用、最新方案或模型来源。模型随意生成的路径、URL 和引用列表不会成为可信事实引用。字段引用可展开查看原值、路径和固定案例指纹。

## 覆盖与版本

`available` 表示所选区域已读取，不保证每个可选字段存在；`not_recorded` 表示检查后记录未提供；`omitted` 表示未完整展开并保留已展示数、已知总数及分页依据；`unavailable` 表示暂不能确认。缺失、空数组、真实零和部分结果分别处理。

授权集合的 `scope_key` 与内容版本分开。内容不可变快照包含全部当前授权公开对象，其 `content_revision` 是作用域快照指纹；回答的 `snapshot_id` 是该快照中单个公开案例的指纹，两者对象不同，不能混为同一个 hash。模型提示、事实引用和工具读取采用同一份冻结内容。授权变化使旧版本失效；内容变化本身不破坏旧回合恢复。

快照不会冻结权限，也不会提供任意文件、Shell、批准或 ERP 写入工具。运行中与等待启动的运行时被保留，空闲实例可回收，实例缓存上限为 32。权限撤销可中止旧作用域。断线恢复及取消先寻找已存在回合，不依赖另建运行时。

## 有界取证

共享事实默认最多展开 24 行、24,000 字符，另保留原来的有界摘要。`case_brief` 返回摘要；`get_case` 支持枚举区域 `actions`、`preserved_documents`、`costs`、`execution`、`readback`、`verification`，以及 `offset/limit`，单页最多 50 项。模型不能设置范围文件或预算。

宿主为每个回合建立预算租约：最多 12 次取证调用尝试（包括被拒绝的请求）、累计证据载荷 128 KiB、单次证据载荷 32 KiB。取消或超时撤销读取资格；SDK 底层请求未结束时保留同快照调度锁，避免旧请求消费下一回合预算。这些限制不等于能中断已经发送到模型服务的请求或计费。

## 已知边界与回退

校验覆盖已知动作数量、成本标签、状态和业务边界，既检查必答事实，也拦截已知错配反例；它不是任意语言的完整证明，可能保守拒绝正确表述。未识别的问题沿用兼容路径，不伪造字段引用。用户需要的明细超过容量时保留不完整状态，不能宣称已穷尽所有记录。

待确认方案、选择冲突和未知执行不能用旧计划证明当前已确认结果。服务端明确拒绝访问或报告回合冲突时，浏览器不再以旧案例生成新答案；网络失败或不支持接口才可使用明确标记的本地兜底。发现关键事实或引用错误时保留失败记录，返回核实事实，不无限重试或改写历史业务证据。
