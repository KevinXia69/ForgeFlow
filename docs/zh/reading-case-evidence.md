# 如何核对案例回答与证据

## 摘要没有显示，不等于记录不存在

大案例会按大小限制生成摘要，摘要可能省略动作、保留单据或历史明细。
当问题需要这些信息时，系统应读取同一授权案例中的相关明细。
只有核对过相关完整区域后，才能说该记录未提供某字段。

工具超时、读取失败、权限变化与字段没有记录属于不同情况。
空数组、明确数值零和缺失字段也不能混为一谈。
列表分页未结束时，应说明还有未展示条目，不能把当前页称为全部。

## 回答依据、读取活动与案例入口

回答依据用于定位支持具体数量、金额或状态的字段。
读取活动表示本轮实际执行过的工具读取。
相关案例入口仅帮助用户自行查看案例和回执，出现链接不代表模型已经读取明细。
如果系统直接提供了足够事实，回答可以不调用工具，但应说明所用证据。

模型不可用时，确定性事实回答仍可使用；界面应标明回答方式，
不把降级回答当作真实模型调用。旧记录没有来源信息时，不推断它已经完成取证。

## 历史版本与权限

正文、字段引用和方案版本须相互对应。同一对话中的旧方案不能与新回执混答。
历史快照固定的是内容，不是访问权限；权限变化后仍需校验授权范围。
来源文档中的文字只是证据，不能成为扩大权限、读取其他工作区或执行操作的指令。
