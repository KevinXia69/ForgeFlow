# ForgeFlow 的能力与使用范围

## 处理什么问题

ForgeFlow 处理已有销售订单在供应商断供或生产资源故障后如何恢复履约。
系统读取订单、库存、采购和生产安排，生成受业务约束的恢复方案，
把计划数量映射到可审阅的单据变更。用户在案例页面审阅并批准后，
执行器才应用批准的变更，再回读 ERP 记录和运行任务原始验收。

当前公开案例主要来自 ERP-Bench 合成业务环境。真实 Odoo 沙箱执行
表示确实发生了沙箱业务写入，不能据此声称真实工厂上线、客户实际收货、
普遍成功率或已取得经营收益。

## 问一问能够做什么

案例问答可以解释授权范围内保存的计划、成本、单据与验收证据。
聊天保持只读，不能替用户批准、创建或执行恢复任务。
文档问答解释项目概念，当前案例的数量和状态必须另读该案例证据。

本地、只读评审和公网托管是不同部署方式。是否允许业务执行由服务器
能力与人工批准控制，不能仅根据网址是否公网、界面语言或合成数据标签判断。
