## 验证与安装

在仓库根目录或 API 镜像的 `/app` 执行：

```sh
python scripts/install_reference_knowledge.py --check
python scripts/install_reference_knowledge.py --tenant TENANT_ID
```

本地开发也可使用 `uv run python`。安装读取已有的 `FORGEFLOW_CONTROL_DATABASE_URL` 和语义检索环境配置，需要有效的租户。`--check` 不联网、不写数据库。安装入口为运维命令，不提供给普通用户选择其他租户。

安装复用 `DocumentCatalog` 和已有增量索引流程；稳定路径为 `reference/supply-recovery-v1/K01.md` 等。重复安装跳过已索引的同内容，索引失败后可以重试，不重复生成文档版本。既有租户的发布代次、其他资料和 ERP 记录保持原样。遇到非本包占用的路径、不同原始出处、已撤回或被拒绝的文档，整包预检会停止。恢复已撤回资料需使用既有的显式生命周期操作。

这些已整理 Markdown 通过本地结构解析器入库，记录 `source_kind=curated_reference`、`classification=research_note` 和 `parser=local_markdown`；不记为 DocumentMind 解析或企业政策确认。目录记录的 `parse_detail.reference_pack` 与文件清单共同保留来源信息。行业资料用于检索参考，实际执行仍绑定当前企业事实、有效制度和批准方案。
